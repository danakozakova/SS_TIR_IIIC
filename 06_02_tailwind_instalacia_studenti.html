Tailwind CSS v4 bez CDN — krok po kroku

Cieľ: doteraz sme Tailwind ťahali cez CDN (<script>). Dnes ho nainštalujeme priamo do projektu — vyrobí nám súbor output.css, ktorý pripojíme k HTML. Triedy a HTML zostávajú rovnaké.

Pracuj v príkazovom riadku Windows: Win + R → napíš cmd → Enter.

Krok 1 — Nainštaluj Node.js

  1. Otvor nodejs.org/en/download
  2. Vyber verziu LTS pre Windows, Windows Installer (.msi) (nie ZIP).
  3. Spusti inštalátor, klikaj Next, nechaj predvolené (najmä npm a Add to PATH), Install, Finish.
  4. Zavri a znova otvor okno cmd.

Over, že to funguje:

node -v
npm -v
✅ Oba príkazy vypíšu číslo verzie (napr. v26.13.0 a 11.20.0 — u teba môže byť iné). Žiadna chyba.

Krok 2 — Vytvor priečinok projektu

mkdir tailwind-projekt
cd tailwind-projekt

mkdir vytvorí priečinok, cd sa doň presunie. Riadok má teraz končiť ...\tailwind-projekt>.

✅ Pred kurzorom vidíš cestu, ktorá končí tailwind-projekt>.

Krok 3 — Inicializuj projekt

npm init -y
✅ V priečinku vznikol súbor package.json.

Nič v ňom zatiaľ neupravuj.

Krok 4 — Nainštaluj Tailwind do projektu

npm install tailwindcss @tailwindcss/cli

Chvíľu to trvá. Je normálne, že sa pridá veľa balíkov (napr. 28) — nástroje potrebujú ďalšie balíky.

✅ Vznikol priečinok node_modules a súbor package-lock.json. Správa končí napr. found 0 vulnerabilities.

Prípadné žlté upozornenie (npm warn ...) ignoruj — nič neschvaľuj navyše.

Krok 5 — Vytvor HTML a vstupné CSS

Otvor projekt vo VS Code (File → Open Folder → tailwind-projekt). Vytvor index.html:

<!DOCTYPE html>
<html lang="sk">
<head>
  <meta charset="UTF-8">
  <link rel="stylesheet" href="./output.css">
</head>
<body class="bg-slate-100 p-8">
  <h1 class="text-3xl font-bold text-blue-600">Tailwind funguje bez CDN!</h1>
  <p class="mt-4 text-slate-700">Táto stránka používa CSS z nášho projektu.</p>
</body>
</html>

A input.css (vedľa index.html) s jediným riadkom:

@import "tailwindcss";

Oba ulož (Ctrl + S). V HTML nesmie byť starý CDN <script>.

✅ V projekte sú index.html a input.css.

Krok 6 — Vygeneruj output.css

Vráť sa do cmd (musíš byť v priečinku projektu) a spusti:

npx @tailwindcss/cli -i ./input.css -o ./output.css --watch
✅ Vypíše sa Done in ... a vznikol súbor output.css.

Terminál zostane „obsadený" — to je správne, sleduje zmeny. Nechaj ho bežať.

Krok 7 — Otvor stránku a over watch

  1. V Prieskumníkovi dvojklikni na index.html → otvorí sa v prehliadači (sivé pozadie, modrý nadpis).
  2. V HTML zmeň text-blue-600 na text-red-600, ulož (Ctrl+S).
  3. Obnov stránku v prehliadači (Ctrl + R).
✅ Nadpis je po obnovení červený. (--watch prepísal CSS; stránku si obnovil ručne.)

Zastavenie sledovania: Ctrl + C v termináli.

Ťahák príkazov

Overenie inštalácie:

node -v
npm -v

Nový projekt (raz):

mkdir tailwind-projekt
cd tailwind-projekt
npm init -y
npm install tailwindcss @tailwindcss/cli

Generovanie CSS (aj na existujúcom projekte):

npx @tailwindcss/cli -i ./input.css -o ./output.css --watch

Zastavenie: Ctrl + C
