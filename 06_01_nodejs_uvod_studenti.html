Node.js — prvé kroky

Dnes sa neučíme JavaScript. Dnes si len vyskúšame Node.js — program, ktorý nám v budúcnosti pripraví Tailwind CSS priamo v projekte namiesto CDN.

Dnes nič neinštaluješ. Pracuješ v online Node playground:

👉 otvor onecompiler.com/nodejs (alebo programiz.com/javascript/online-compiler).

Kód píšeš vľavo, spúšťaš tlačidlom Run, výstup sa ukáže v konzole. Je to to isté, ako keby si spustil(a) node subor.js na počítači.

Úloha 0 — tvoj prvý program

Zmaž všetko, čo je v playgrounde, a napíš jeden riadok:

console.log("Ahoj, volám sa ...");

Stlač Run. V konzole sa má objaviť tvoj text. Práve si spustil(a) JavaScript mimo prehliadača — bez stránky.

Úloha 1 — Predikuj: čo sa vypíše?

Najprv tipni výsledok (napíš si ho), až potom spusti a over:

console.log("5 + 3 = " + (5 + 3));
console.log("5 + 3 = " + 5 + 3);

Prečo sú výsledky rozdielne? Zapíš si vysvetlenie jednou vetou.

Úloha 2 — Premenné a výpočet

Ulož dve čísla do premenných a vypíš ich súčet:

const a = 12;
const b = 30;
console.log("Súčet je:", a + b);

Potom skús: zmeň čísla, pridaj tretiu premennú, vypíš aj súčin (*).

🎯 Mini-projekt — Kalkulačka voľného miesta

Napíš program, ktorý spočíta voľné miesto vo flex kontajneri — ten vzorec z testu, teraz ako Node program.

Musí obsahovať:

  • ✅ premenné sirkaRodica, pocetDeti, sirkaDietata, gap
  • ✅ výpočet: volneMiesto = sirkaRodica − pocetDeti · sirkaDietata − (pocetDeti − 1) · gap
  • ✅ výpis výsledku peknou vetou cez console.log
  • ✅ otestuj dva príklady — stačí zmeniť čísla v premenných

Príklady na kontrolu:

  • rodič 400, 3 prvky po 80, gap 0 → voľné miesto 160 px
  • rodič 500, 4 prvky po 60, gap 16 → voľné miesto 212 px

Postup: najprv si napíš premenné, potom jeden riadok výpočtu, potom výpis. Spúšťaj priebežne, nie až na konci.

Pozor: gapov je o jeden menej ako prvkov → (pocetDeti − 1).

⭐ Bonus — pre tých, čo stihli

  1. Dopočítaj medzeru pri justify-between: medzera = volneMiesto / (pocetDeti − 1). Pre 400/3/80 má vyjsť 80 px.
  2. Nech program oznámi, ak sa prvky nezmestia (voľné miesto je záporné) — použi if ... else.
  3. Zisti (cez AI alebo doma s nainštalovaným Node), čo robí process.argv — ako do programu dostať čísla priamo z príkazu.
